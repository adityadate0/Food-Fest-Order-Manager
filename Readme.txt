SUMMER FESTIVAL 2026 - STALL POS SYSTEM SETUP
============================================================

1. Extract this entire .ZIP folder onto your desktop (Do not run it from inside the zip!).
2. Double-click the file ending in `.exe` to launch the server.
3. A black command window will open, and a master control dashboard will automatically pop up in your browser.
4. Connect all tablet devices (Front Desk, Station A, Station B) to the laptop's Wi-Fi / Hotspot network.
5. Type the exact URLs displayed on the master dashboard screen into the tablet web browsers.

* Note: Leave the black window running on the main laptop the entire time you are taking orders!
* To shut down and automatically save the final Excel transaction logs, click the red "Quit" button on the Front Desk screen.
